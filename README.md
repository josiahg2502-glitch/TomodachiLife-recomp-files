# TomodachiLife-recomp files

Files for [TomodachiLife-recomp](https://github.com/josiahg2502-glitch/TomodachiLife-recomp): nothing here needs to be
downloaded by hand.

- **Release `installer-tools`**: third-party tools the installer downloads, kept here so an install never depends on
  another site. Each is unchanged and checked by its SHA-256 (pinned in the installer):
  LLVM/clang 9.0.0 (Apache-2.0 with LLVM exception; the files of the official installer, as a zip),
  FFmpeg 8.1.3 LGPL build (source link and licence inside), libopus 1.6.1 (MSYS2 ucrt64 package, BSD),
  and `raw_data.cpp` / `mii_types.h` from suyu-emu/suyu-v0.0.4 at c0dd2ff5 (MIT).
- **`screenshots/`**: pictures of the port running, for its README.
